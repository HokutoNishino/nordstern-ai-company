# 第1回記事 構成案

## 仮タイトル

生成AI導入はツール選びから始めたらあかん——中小企業が最初に考えるべきこと

## 導入

- 「ChatGPTを契約すれば、勝手に業務が片付く」という期待に軽くツッコむ
- AIに興味はあるが、最初の一歩が分からない経営者の状況を示す
- この記事では製品比較ではなく、導入前に決めるべき順番を説明すると約束する

## 1. AIツールを契約しただけでは、業務は変わらへん

- ツールの導入と業務改善は別物
- 誰が、どの業務で、何のために使うかが必要
- 目的が曖昧なままだと「何に使えばいいか分からない」で止まる
- `[要確認: 書き手自身の体験または失敗例]`

## 2. 最初に見るべきは、AIの機能ではなく日々の業務

- 時間がかかっている業務
- 同じことを繰り返している業務
- 入力と出力がある程度決まっている業務
- 最終的に人が確認できる業務
- メール、議事録、定型文書など身近な例を示す

## 3. 最初の候補を選ぶ3つの基準

### 繰り返し発生しているか

一度きりの作業より、毎日・毎週発生する作業を優先する。

### 効果を時間で測れるか

導入前後の所要時間を比較できる業務を選ぶ。

### 間違っても人が止められるか

AIに任せきりにせず、人が確認して修正できる範囲から始める。

## 4. いきなり任せたらあかん業務もある

- 個人情報や機密情報を無造作に入力する業務
- 法務、税務、採用など判断の影響が大きい業務
- 間違いを人が発見できない業務
- 自動化による事故や損失が大きい業務
- ここでは笑いを入れず、慎重に説明する

## 5. 今日やることは、業務を3つ書き出すだけ

- ツール契約や大きな予算はまだ不要
- 「よく発生する」「時間がかかる」「人が確認できる」の3条件で探す
- 読者が紙やメモに業務を3つ書ける簡単な問いを示す

## まとめ

- AI導入の出発点はツールではなく業務
- 小さく試し、人が確認し、効果を測る
- 次回は、最初にAI化しやすい具体的な業務5選を紹介する

## 不足素材

- 書き手が最初にAIで試した業務
- ツール先行でうまくいかなかった経験の有無
- 読者に紹介できる具体的な入力例
- 実測した時間または費用
