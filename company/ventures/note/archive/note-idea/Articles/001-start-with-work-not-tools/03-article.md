# 生成AI導入はツール選びから始めたらあかん——中小企業が最初に考えるべきこと

「生成AIを導入したいんやけど、どのツールを契約したらええの？」

AIの相談で、最初に出てきやすい質問です。ChatGPTをはじめ、いろいろなサービスがありますから、まず製品を選びたくなる気持ちはよう分かります。

ただ、ここでいきなり料金表を見比べ始めると、話がややこしくなります。機能は多い、プランも多い、横文字も多い。気づけばAIを導入するはずが、料金表を眺める業務だけ増えていた——となったら、ちょっと切ないですよね。

生成AI導入で最初に考えたいのは、ツールではありません。

## 今日やることは、業務を3つ書き出すだけ

次の質問を見ながら、思いつく業務を3つ書き出してみてください。

1. 毎日または毎週、繰り返している業務は何か
2. 担当者が「またこの作業か」と感じている業務は何か
3. AIが下書きを作り、最後に人が確認できる業務は何か

立派な導入計画は、まだ要りません。まず3つ出せたら十分です。初日から全社改革まで考えたら、そら頭も重たくなります。
