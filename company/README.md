# Nordstern AI Company Workspace

This directory is the durable operating memory for a multi-venture company.

## Structure

- `portfolio.md` — all active, discovery, and backlog ventures with one entry point each.
- `core/` — company-wide material that applies across ventures.
- `ventures/` — one isolated workspace per active business or approved discovery track.

## Routing rule

Read `portfolio.md` first, choose one venture, then work only inside that venture unless a company-wide policy is required. A venture owns its briefs, decisions, reports, product files, evidence, and archive. Cross-venture policies and portfolio decisions belong in `core/`.

Backlog ideas remain in `portfolio.md`; do not create directories for them until active discovery or execution is approved.

The AI departments can recommend external actions, but real-world actions such as sending outreach, spending money, production deployment, signing agreements, or deleting data require human approval.
