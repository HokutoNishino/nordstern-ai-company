# Company Core

This directory contains material that applies across all Nordstern ventures.

## Contents

- `strategy/` — founder-provided company strategy and launch plans.
- `briefs/` — company-wide constraints, policies, budgets, and operating context.
- `decisions/` — portfolio and operating decisions that affect more than one venture.
- `reports/` — company-wide audits and migration or operating verification.
- `recovery/` — recovery-only artifacts excluded from routine context reads.
- `templates/` — reusable artifact templates.

All ventures inherit `briefs/2026-08-17-founder-compliance-boundary.md`. Venture-specific prospect registers and operating checklists stay inside the owning venture.

Customer hypotheses, venture-specific decisions, product work, publishing state, and venture evidence belong under `company/ventures/<venture-id>/`.
